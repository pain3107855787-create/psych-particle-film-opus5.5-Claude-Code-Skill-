# 踩过的坑

- **TTS 在 Git Bash 下段错误** → 配音一律用 PowerShell 跑（命令见 SKILL.md），放后台。IndexTTS-2.5 每句约 6 秒（8GB 显存，峰值 6.2GB）；别加载情绪模块，显存溢出后每句要 3.5 分钟。
- **语音识别分低**：数字被转成阿拉伯数字是正常的；其他低分要查。判断方法：同一个词在别的句子里识别正确、只在这句错 → 配音读偏了（例："跟着消失"被读成"跟着相识"）。
  修法：改措辞（句尾加"了"等让收尾完整）+ `--only id --takes 5 --seed 41` 重配。
- **爆散的低频冲击盖住关键词** → boom 增益 ≤ .35，或错开半拍。
- **playwright `page.evaluate` 只接收一个参数** → 多个值包成数组 `[a, b]`。
- **np.convolve 做长音频滑动平均会卡死**（数百万采样 × 上万核）→ 用累加和（tools/mix.py 已处理）。
- **canvas 状态泄漏**：主题 bg/deco 里改了 textAlign 等要 save/restore，否则字幕会错位。
- **改了 film.js 或文案后，旧的渲染进程要先停掉**再重渲。
- **封面**：`E.clean = true` 渲染无字幕/无角标的干净帧，再叠标题；两张都要（3:4 1080×1440 + 4:3 1440×1080）。
- 字体是按片中用到的字下载的子集：改了文案/画面文字后要重跑 `node tools/fonts.mjs`（build.sh 已包含）。
- 抽帧检查时注意：某一时刻元素"没出现"可能只是还没到进场时间，对照 timeline.json 再判断。
- **封面取帧**：别取在粒子变形的半路（会是一团乱点），挑本期最有代表性、构图干净的静止时刻。episode.json 的 cover 可调：
  `line/offset` 取帧时刻、`focusX/focusY` 对准哪里、`zoomTall`（3:4 竖版缩放，默认 1.05；主体分散在左右两端时用 .8 左右）。
  封面帧不画屏幕层（滑条等）；片子里右上角的元素在竖版封面上容易压到 Pain 水印，可在 film.js 里用 `E.cover && E.cover.h > E.cover.w` 判断后不画。出完一定要 Read 两张封面检查。
- **漏念英文字母**（如"世界A"念成"世界"）：旧版打分只算汉字，会选中漏字母的版本。已修（字母计分）；质检时仍要看识别文本里字母在不在。
  手动换版本：`cp voices/takes/<id>_<k>.wav voices/<id>.wav`，并更新 voices/dur.json 里的时长。
- **封面上的底部小标签**（柱子名、领奖台名等）会被大标题压住露出半截 → 在 film.js 里对这类标签加 `!E.cover` 判断，封面上不画。
- **无配音片的封面**：文字旁白是 film.js 自己画的（caption()），不受 E.clean 控制，会被画进封面 → caption() 里加 `if (E.cover) return`（预期管理踩过）。
- **封面上的大字叠层**：film.js 里自己画的引用 / 金句（big()、neon）在封面上会和标题叠在一起 → 这类叠层也加 `!E.cover`（巴纳姆踩过）。

- **只用粒子拼的字看不清**（2026-10-19 用户：苦乐参半、救赎式叙事"只有粒子"）：粒子聚成字后要叠一层实体霓虹字（film.js 的 solid()），粒子降到 alpha .55 当质感；这种句子 gapAfter 给 .9，让字停够。

- **3D 关键帧跨章节被插值**（嫉妒、过度自信踩过）：wk() 关键帧之间一直缓动，某参数（调光线、裂纹）要"到某章才出现"，必须在那章开头补一个保持帧（如 `wk(CH.x.card.a - .01, {wire: 0})`）；硬切用 `hard: 1`，且硬切之后别再有更早场景的关键帧。
- **IndexTTS 读不准的专有名词**：珠穆朗玛（拼音标注也救不回来）→ 口播改简称（珠峰），字幕保留全称；"替你"常读成"踢泥"→ 换同义词（帮你）。
- **IndexTTS 拼音标注也会翻车**（情绪容纳）：`<脑|NAO3>` 被念成字母"N.O."，比不标还糟 → 标了拼音也要看识别结果，不行就换说法（"脑成像发现" → "一项研究发现"）；"比昂说"常被读成"比方说"、"只回了"读成"指挥了"，同样改口播措辞。"炭"识别常在 碳/探/贪/摊 之间跳，标 `<炭|TAN4>` 后仍要提醒用户亲耳听。
- **glassMan 这类用离屏画布的元素**：每帧复用画布前要重置 globalCompositeOperation / globalAlpha（否则 source-atop 残留，第二帧起什么都不画）。
- **3D 物体和 2D 人物对位**：人物脚底放在 3D 地面 y=-1.25 上，用 S3.project 算出位置；炭要放进胸口就按 "脚底 + .62×身高" 算 3D 坐标，别凭感觉写，否则炭会跑到头顶。
- **`<着|ZHE5>` 拼音标注会被念成字母**（自我分化："跟着它摆"→"跟G他白"）："着"不要标拼音，默认读音基本对；标了的句子一定看识别结果。
- **tts_index.py 识别模型下载中断**时会静默跳过打分（全部 1.00 且识别文本为空）→ 用 tools/rescore.py 事后补打分、挑版本。
- **文字颜色别和画面主体同色**（反脆弱 2026-10-21 用户：火在的时候字和火颜色太像看不清）：强调色要和画面最亮的东西对比（火 / 暖光场景用冰蓝 #9fe8ff），画面里的字一律垫黑色光晕（film.js 的 halo()），大标题 / 名片卡 / 结尾金句后面再加一块暗色衬底（plate()）；叠在全屏特效（裂缝等）上的字要画在特效之后。

- **IndexTTS 启动时联网检查会卡死**（2026-10-27 内核稳定：日志停在 "Xet Storage... Falling back to regular HTTP download" 十几分钟不动）→ 配音命令前加 `$env:HF_HUB_OFFLINE='1'`；离线时识别模型加载不到、不打分，配完再去掉这个变量跑 `tools/rescore.py` 补打分。
