# 创意方法（2026-10-19 起，每期写稿前必看）

## 用户的核心想法（原话提炼）
- **创新 = 旧东西的新组合**。参考视频是拿来"看他们用了什么特效"的，然后**我们自己组合出没出现过的特效**——不是照抄某一个元素。
- **开头几秒让观众共情、留下来"等一个东西"**：等最后的答案，等"这是不是在说我"。钩子 = 共情 + 悬念，两样都要。
- **高级的图形效果是为了吸引人**：每期至少一个"观众没见过"的视觉瞬间，值得截图。
- **每一期都围绕主题出现新的东西**：不做固定的系列主角；人物、道具、母题都按本期主题重新想。
- **可以用网上真实的案例图片**，不必全部自己画（见文末"真实图片"）。

## 每期的创意清单（写文案表格时一起交给用户）
1. **视觉母题**（必做，给 2~3 个备选）：先问"这个概念在现实里看起来像什么？"再挑一个**能随剧情变化**的东西，让数据、故事、结尾都围着它转。
   - 傲慢 → 墙上的影子 = 自我估计（影子随每句傲慢长大、戴王冠；数据画成"人 12 vs 影子 62"；结尾影子缩回原样、王冠滚走）
   - 备选库：嫉妒 → 每人头顶一盏灯，看别人的灯越亮自己越暗，最后发现是同一根电线；拖延 → 越推越重的门，真推开时很轻；冒充者综合征 → 越成功越厚的面具，摘下后的脸和面具一样；沉没成本 → 往井里扔硬币，镜头拉远旁边就是出口；聚光灯效应 → 自己头顶的追光巨大，别人眼里只是个小光点
2. **开头的"等"**（必做）：第 0 帧大字反问 + 主角在场；再埋一个**要到结尾才揭晓**的东西——
   - 站队：先让观众做一个 1 秒能懂的选择（"你在平均线以上还是以下？"/"两份工资你选哪个？"），结尾揭晓"大多数人的选择"或"你的选择说明了什么"
   - **对号入座（用户最认可，2026-10-22）**：开头放观众亲口说过 / 听别人说过 / 心里想过的原话或小动作（口头禅、内心独白、聊天记录、习惯动作），让人一秒觉得"这句我说过""TA 就这么跟我说的"。形式每期换，别套模板（依恋理论用的是两人对峙："我们现在就把话说清楚" vs "我想一个人静一静"）
   - 悬置的画面：一个被遮住 / 没说完的东西（盖着布的镜子、没拆的信、倒计时），结尾才打开
3. **反转结尾**（按题选用）：前面让观众舒服地站在"看别人"的位置，最后一句把镜头转向观众自己（"你刚才想到某个人的时候……你的影子，也长了一点"）。批判类概念适合；安慰类（依恋、自我价值）别用，会显得刻薄。不说教。
4. **一个新特效**（必做）：从下面的特效池挑一个没用过的，或用"组合公式"现场想一个；做成 motifs.js 元素 + 补图鉴。

## 组合公式（想新特效用）
**[一个已有手法] × [一个本期母题] × [一个意外的物理行为]**。例：字幕（已有）× 傲慢 × "有重量" → 关键词像铁块一样砸到地上、把地面砸裂。

## 特效池（✅ = 已实现，可直接用）
- ✅ 影子 ≠ 本人：墙上的影子按"自我感觉"缩放（`M.flatMan` 的 shadow）
- ✅ 一字炸开：一个字被放大 → 念头沿引线长出 → 故障炸开 → 留核心字（`M.wordBurst`）
- ✅ 划掉改写（`M.strikeFix`）
- ✅ 真实照片：暗房显影 / 双色调 / 网点 / 扫描线显现 / 撕开 / 拍立得 / 档案照 + 打码 + 证据墙红线（`M.photo` `M.redString`）
- ✅ 字有重量：关键词像铁块一个字一个字砸下来，压扁按钮、砸裂地面（拖延 film.js 的 heavyWords）
- 数字变人群：93% 拆成 93 个小人走进画面，剩下 7 个站在另一边
- 字中穿越转场：镜头推进一个大字的笔画缝隙，从笔画里穿出来就是下一个场景
- ✅ 时间冻结：一切静止 + 去饱和 + 取景框 + 时钟停住，镜头绕着转，标签一张张亮起（拖延：paperwave 的 clock/lit + film.js screen()；配乐用 sfx.py 的 MUSIC_GAIN 同时停下）
- ✅ 视频自己"走神"：整帧被手指往上划走，刷到一条无关短视频，再划回来"……刚才说到哪了？"（拖延 screen() 的 soapVideo；适合讲注意力 / 逃避 / 即时满足）
- ✅ 视频扫描观众：画面压暗，人脸识别框对准屏幕外的你，读数"嘴角上扬 0.3 秒"，最后"记录已删除 ✓"（嫉妒 screen()；适合讲观众自己也有的"不体面"情绪：幸灾乐祸、偷看、比较）
- ✅ 调光器：两扇窗被一根线连着此消彼长，镜头拉远后线被剪断、每盏灯都有自己的电线（嫉妒：零和错觉）
- ✅ 藏宝图：把散落的情绪对象连成一条路线，俯视时变成地图，金色终点 = 你真正想要的（嫉妒结尾）
- ⚠️ 观众亲自答题（2026-10-22 用户：倒计时 / 等观众作答的几秒没有任何信息，观众会划走——别再用空等，题目要边给信息边推进）：开场让观众给"九成把握"的范围（题卡 + 3 秒倒计时 + 可暂停），第三题问"这条视频有多长"，最后一句揭晓（成片时长用 episode.json music.tail 调到和念出的数字一致）——让观众亲身中一次偏差（过度自信）
- ✅ 会改口的进度条："本期还剩 0:30" → "重新估算中……" → 越估越长（计划谬误）
- ✅ 冰面碎开 + 坠入水下：3D 碎块下沉、气泡、光柱，配乐用 MUSIC_GAIN 闷住（过度自信的代价）
- ✅ 套娃屏幕：结尾主角的电脑里正在播这条视频（screen() 里把当前帧缩小画进屏幕矩形，循环 3 次）——把镜头转向观众的反转结尾
- ✅ 烫手的字：聊天气泡里的字烧红、逐字热浪扭曲、往上冒火星，被接住后慢慢冷成奶白（情绪容纳 film.js 的 hotText）
- ✅ 视频自己当一次容器："下面三秒，这个视频什么都不说"——画面压暗、配乐用 MUSIC_GAIN 真的停下，只剩一点余温的噼啪声（情绪容纳）
- ✅ 撤回重答：结尾回到开头同一个聊天界面，把当时那条回复撤回（"你撤回了一条消息"），换成正确答案发出去（情绪容纳；首尾呼应 + 站队揭晓）
- ✅ 配乐被带快：讲"被别人的情绪带着走"时，背景音乐本身真的变速变调（sfx.py 写 MUSIC_WARP=[(t0,t1,倍数)]，mix.py 处理；film.js 用同一个公式算画面相位），再配一句"连这条视频的配乐，都被带快了"+ 右上角速度读数（自我分化）
- ✅ 画面在晃、字幕不晃：screen() 里把整帧复制后抖动重画，字幕和读数在之后画所以不动——"就像现在，画面在晃，字幕没动"（自我分化；讲稳定 / 不被带跑）
- ✅ 屏幕碎了，再用金子补上（金缮）：讲"脆弱"时整屏像玻璃一样裂开（screen() 里画程序生成的裂纹 + 震动），结尾裂缝一条条灌进金子、发光（反脆弱 film.js 的 CRACKS）；适合讲伤痛、成长、修复
- ✅ 风把字幕吹走 / 同一阵风让字烧旺：sub() 的 blow / flare 参数（反脆弱）
- 镜像不同步：镜子里的人比现实慢半拍 / 做着不同的动作
- 心电图变地平线：一条心跳线拉平，变成下一个场景的地面
- 纸被撕开：画面像纸一样被撕开，露出底下另一层"真相"
- ✅ 抽字：一句话里的某个字（或一串字）发光上浮、飞走，剩下的字合拢补位（`M.pullChar`；沉没成本：结尾五句"都……了"里的"都"被抽进井里，"来都来了"抽"都来"变"来了"）
- ✅ 已观看计时器：右上角"已观看 01:30"按真实播放时间走，旁白说出同一个数，再让观众当场中一次偏差（沉没成本："都看到这儿了"）
- ✅ 价签翻面：3D 卡片在空间里翻过来，正面"你得到的"、背面"你放弃的"（scenes3d `phones` 的 tag + drawTag；机会成本）
- ✅ 幽灵轨道：没过上的那种人生画成半透明、RGB 错位、扫描线闪烁的一层，和主画面并排播放（机会成本 film.js 的 ghost()）
- ✅ 实时手机界面：3D 手机屏幕 = 每帧重画的 CanvasTexture（聊天记录越往后越短、交友软件一张张滑走、打字光标）（scenes3d `phones`）
- ✅ 换框：画的内容不动，3D 画框一直在换（旧框掉下去、新框落下来回弹），框换了光的冷暖和调色跟着变；框越长越宽把画吃掉；结尾所有框掉到地上（框架效应，scenes3d `gallery`）
- 被涂黑的字：一句话里的词一个个被黑条涂掉，只剩下真正想说的那几个字
- 证据墙：真实照片 + 红线 + 档案编号，像在破案一样把研究串起来
- 显影真相：一张照片在暗房药水里慢慢显影，先出现的高光就是关键线索

## 真实图片
- 工具：`python tools/fetch_image.py "英文关键词"` → 候选在 `assets/_candidates/`（看 `contact.jpg` 联系表）→ `--pick 序号 --name 文件名` 存进 `assets/`，作者 / 授权 / 原链接自动写进 `assets/credits.json`，发布文案自动附"图片来源"。
- 只用 **Wikimedia Commons 的自由授权**（公有领域 / CC0 / CC BY / CC BY-SA，工具已过滤）；**不抓新闻图片、不抓版权不明的图**。用户自己提供的图放进 `assets/`，由用户负责授权，credits.json 里手动补一条。
- 适合：历史照片、科学家肖像、实验装置、真实场景（车流、教室、法庭）。真人面孔做真实案例时用 `redact` 打码。
- 风格统一：一律过 `fx: 'duotone'` / `'mono'` / `'halftone'` 调到本期配色，别把原色照片直接贴进画面。
- 用法：film.js 的 build() 里 `M.img('assets/x.jpg')` 注册（渲染器会等图片加载完），overlay 里 `M.photo('assets/x.jpg', x, y, w, h, t, al, {...})`。
