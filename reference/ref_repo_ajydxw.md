## 和我们流程的差别（值得学的）
1. **全片以拍子为唯一时间单位**：`Q(k) = 相位 + k·拍长`，每段固定 16 / 32 拍（段落切换点 = 小节线），画面和音效都写成 `Q(36.5)` 这种拍号，天然对齐。我们是"配音时长 → 吸到拍子"，他们是"先定拍子网格 → 内容填进去"。
2. **音乐塑形（最值得抄）**：把配乐预先算出三个版本——低通 380 Hz（闷）、1100 Hz（半闷）、原声——按时间曲线交叉淡化：开场蓄力时音乐变闷，揭晓概念那一拍"砰"地全打开；重击下面做 sidechain 压低（−4~−6 dB，0.4~0.6 s）；高潮前留半拍全黑 + 静音；结尾黑场金句完全静音。我们只有 MUSIC_GAIN（音量），没有"变闷 / 打开"。
3. **全局后期栈，每帧都过**：泛光（缩到 480×270 → 阈值 → 模糊 → screen 叠回）、色散 chroma、闪白 / 闪黑、暗角、动态颗粒（overlay，30fps 换种子）、**震动表** SHAKES=[[拍点, 强度, 时长]…]（噪声衰减抖动）、径向 zoomBlur、横 / 竖 motionBlur。各段只返回 {bl, ca, fl} 参数，master 统一做。
4. **右下角常驻小卡**：心率数字 + 心电图 + 倒 U / 象限小图 + "你在这"光标，全片跟剧情走；**心率关键帧积分出每次心跳的时刻**（gen_heartbeats.py），画面心电图和音频心跳声共用同一份 heartbeats.json。
5. **逐字动画排版** kText(str, …, fn(i,n)→{dx,dy,s,a,rot})：slamT（2.2 倍砸下 + 落地回弹余震）、stampT（印章 2.8 倍盖下、斜 −0.12）、打字机、逐字弹入。大字都"有重量"。
6. **固定叙事骨架**：吸睛开头（生活场景失控，心率飙升）→ 亮出知识点（定格"❚❚ 先暂停一下" → 碎片倒吸锻成大字 → 定义卡 → 图标连成曲线，"你在这"落点）→ 共鸣举例 ×3~5（每个：回到曲线 → 光标滑到下一节点 → 口头禅大字砸下 → 镜头钻进节点 → 小剧场 → **结算卡/印章** → 拉回曲线）→ 讲原理（大脑）→ 给方法 ×3 → 留白结尾（黑场白字金句、静音）。
7. **剧本是逐拍表格**：时间 | 拍 | 画面 | 文字 | 声音，四列对齐（docs/剧本_全片修订版.md）。

## 不照搬的
- 他们每期都"给方法 ×3"——用户不喜欢说教式方法建议（narrative.md），我们用描述 / 留白收尾。
- 固定 7 段模板会让每期长得一样——用户要求每期换结构（keep-innovating），只借手法。
