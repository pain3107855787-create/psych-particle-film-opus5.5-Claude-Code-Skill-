# 叙事结构（参考视频提炼 + 两期实践）

一句旁白 = 一个画面节拍。短句、有停顿，像讲故事，不像念课本。

## 骨架（约 20~25 句，成片 1:40~2:20）
1. **钩子（3~5 句）**：**第 0 帧就要有内容**——两行大字提问（关键词强调色+下划线）+ 主角已在画面上，首句 0.15s 开口（episode.json `startAt: 0.15, noFadeIn: true`，首句 `noSub: true`）；前 10 秒让一个读数不停变化，吊住"最后会变成多少"。
   一个让人代入的具体瞬间或一个"浪漫/直觉"的说法。
   - 情感类：具体场景（"晚上十一点，TA说：我先睡了。"）
   - 道理类：一个问题（"硬币连开 5 次正面，第 6 次你押什么？"）
   - 结尾抛出疑问或不安，然后 **白光闪切** 进入正题。
2. **转折：年份 + 科学家**（"1930年代，心理学家皮亚杰……"）。用字卡：年份大字 + 英文名 + 中文名。
3. **拆解（6~8 句）**：实验 / 数据 / 一步步推出概念名。概念名最后由粒子拼字出现（配英文小字）。
4. **回到故事 / 延伸（5~6 句）**：把概念放回钩子的场景里，制造情绪最低点（爆散、断开、消失）。
5. **反转 / 揭示（2~3 句）**：镜头拉远看到全貌，或研究被推翻，给出反直觉的真相。
6. **收尾（3~4 句）**：一个意象（月亮、硬币没有记忆）+ 一句可以截图的金句尾卡。

## 写稿规则（用户偏好）
- 恋爱/亲密关系里的另一半写 **TA**；`say` 里写"他"（发音相同，避免 TTS 念字母）。
- **不要说教式的"方法建议"**（如"当不安来时，去回想……"）。用描述和意象收尾，留白。
- 每句 `text` 是字幕（用 `{红}` `<第二色>` 标关键词，每句 1 处为宜），`say` 是朗读稿：数字写汉字（一九三零年），可加 `[breath]` 和逗号控制停顿。
- 情绪节点后加 `gapAfter`（1.0~1.8 秒）给画面和音乐留呼吸；默认句间 0.55 秒。
- 时长按内容走，不必卡 120 秒。
- 引用的研究要核实：人名、年份、结论别张冠李戴（例：情感客体恒常性来自马勒 Mahler，不是鲍尔比）。不确定的数字宁可不写。
- 写完 **先把文案（带画面说明的表格）发给用户确认**，确认后再配音。
